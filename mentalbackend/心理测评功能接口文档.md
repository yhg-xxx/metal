# 心理测评功能接口文档

## 功能概述

本接口文档描述了心理咨询系统中的心理测评功能，包括测试题目管理、测试记录管理、答题详情管理和心理评估报告管理。

## 技术栈

- 后端框架：Spring Boot 3.5.6
- 数据库：MySQL 8.0.37
- ORM框架：MyBatis Plus 3.5.9
- 编程语言：Java 17

## 接口列表

### 1. 获取测试题目

**接口地址**：`GET /api/tests/questions/{learningPackageId}`

**请求参数**：
- `learningPackageId`：学习包ID，路径参数

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "learningPackageId": 1,
      "questionType": "SINGLE_CHOICE",
      "questionText": "你是否经常感到焦虑？",
      "options": "[{\"id\":1,\"text\":\"是\"},{\"id\":2,\"text\":\"否\"}]",
      "correctAnswers": "[1]",
      "explanation": "焦虑是一种常见的情绪状态，过度焦虑可能影响心理健康。",
      "points": 10,
      "psychologicalDimension": "情绪健康",
      "sortOrder": 1,
      "status": "ACTIVE",
      "createdTime": "2025-12-19T19:34:16"
    }
  ]
}
```

### 2. 创建测试记录

**接口地址**：`POST /api/tests/records`

**请求参数**：
- `userId`：用户ID，表单参数
- `learningPackageId`：学习包ID，表单参数
- `totalQuestions`：总题目数，表单参数

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "userId": 1,
    "learningPackageId": 1,
    "totalQuestions": 10,
    "answeredQuestions": 0,
    "correctAnswers": 0,
    "score": 0.00,
    "timeSpentSeconds": 0,
    "timeLimitSeconds": 900,
    "status": "IN_PROGRESS",
    "startedTime": "2025-12-19T19:34:16",
    "submittedTime": null
  }
}
```

### 3. 保存用户答案

**接口地址**：`POST /api/tests/answers`

**请求体**：
```json
{
  "testRecordId": 1,
  "questionId": 1,
  "userAnswers": "[1]",
  "isCorrect": 1,
  "timeSpentSeconds": 30
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "保存答案成功",
  "data": null
}
```

### 4. 完成测试

**接口地址**：`PUT /api/tests/records/{testRecordId}/complete`

**请求参数**：
- `testRecordId`：测试记录ID，路径参数
- `correctAnswers`：正确答案数，表单参数
- `score`：得分，表单参数
- `timeSpentSeconds`：用时（秒），表单参数

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "userId": 1,
    "learningPackageId": 1,
    "totalQuestions": 10,
    "answeredQuestions": 10,
    "correctAnswers": 8,
    "score": 80.00,
    "timeSpentSeconds": 600,

    "status": "COMPLETED",
    "startedTime": "2025-12-19T19:34:16",
```

## 代码结构

### 实体类
- `TestQuestions`：测试题库实体
- `TestRecords`：测试记录实体
- `TestAnswers`：测试答题详情实体
- `PsychologicalAssessments`：心理评估报告实体

### Mapper接口
- `TestQuestionsMapper`：测试题库Mapper
- `TestRecordsMapper`：测试记录Mapper
- `TestAnswersMapper`：测试答题详情Mapper
- `PsychologicalAssessmentsMapper`：心理评估报告Mapper

### Service接口
- `TestQuestionsService`：测试题库Service
- `TestRecordsService`：测试记录Service
- `TestAnswersService`：测试答题详情Service
- `PsychologicalAssessmentsService`：心理评估报告Service

### Service实现类
- `TestQuestionsServiceImpl`：测试题库Service实现
- `TestRecordsServiceImpl`：测试记录Service实现
- `TestAnswersServiceImpl`：测试答题详情Service实现
- `PsychologicalAssessmentsServiceImpl`：心理评估报告Service实现

### Controller
- `TestController`：心理测评Controller，处理所有测评相关请求

## 功能流程

1. **获取测试题目**：用户根据学习包ID获取测试题目
2. **创建测试记录**：用户开始测试时创建测试记录
3. **保存用户答案**：用户每答一题保存一次答案
4. **完成测试**：用户提交测试后，系统计算得分并更新测试记录状态
5. **生成评估报告**：根据测试结果生成心理评估报告
6. **获取评估报告**：用户查看自己的心理评估报告

## 错误码说明

| 错误码 | 描述 |
| --- | --- |
| 200 | 成功 |
| 400 | 请求参数错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 使用说明

1. 确保数据库已创建并执行了`psychological_consultation_system.sql`脚本
2. 启动Spring Boot应用
3. 使用API测试工具（如Postman、Insomnia）调用相关接口
4. 建议在调用接口前先进行用户认证

## 注意事项

1. 所有接口均返回统一的JSON格式响应
2. 接口请求和响应中的日期时间格式为ISO 8601格式
3. 心理评估报告中的JSON字段需要按照指定格式传递
4. 建议在生产环境中添加接口认证和授权机制
5. 测试题目和评估报告的JSON数据需要进行适当的校验
